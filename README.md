# 🚗 Dev.City  An educational pixel-art game for Software Engineering students. Navigate the city as a Tech Lead and make decisions based on the CASEL socioemotional framework.  🎮 **Features**: 12 scenarios, 3 difficulty levels, radar chart. 🛠 **Tech**: HTML, CSS, JS, Python. 👥 **Team**: Kaio, Thyago, Calebe , Harik.
